# eugene-middleware

**Eugene - OpenAPI Interface Kit - oink!**

HTTP middleware for OpenAPI 3.x request validation and security enforcement in Go.

## Overview

`eugene-middleware` validates incoming HTTP requests against your OpenAPI specification and enforces security requirements. It's designed to work seamlessly with code generated by [eugene](https://github.com/kolah/eugene), but can be used standalone with any Go HTTP server.

**Features:**

- Request validation against OpenAPI 3.x specs
- All 6 OpenAPI security schemes supported
- AND/OR security requirement semantics
- Type-safe security context for handlers
- Custom error handling
- Works with any `http.Handler` compatible router

## Installation

```bash
go get github.com/kolah/eugene-middleware
```

## Quick Start

```go
package main

import (
    "context"
    "net/http"

    middleware "github.com/kolah/eugene-middleware"
)

func main() {
    spec := `
openapi: "3.0.0"
info:
  title: My API
  version: "1.0"
paths:
  /users:
    get:
      security:
        - bearerAuth: []
      responses:
        "200":
          description: OK
components:
  securitySchemes:
    bearerAuth:
      type: http
      scheme: bearer
`

    opts := middleware.DefaultOptions()
    opts.Security.RegisterBearer("bearerAuth", func(ctx context.Context, token string) (*middleware.BearerAuth, error) {
        if token != "valid-token" {
            return nil, middleware.NewUnauthorizedError("bearer", "invalid token")
        }
        return &middleware.BearerAuth{Token: token}, nil
    })

    mw, err := middleware.New(spec, opts)
    if err != nil {
        panic(err)
    }

    handler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        sec := middleware.GetSecurityContext(r.Context())
        w.Write([]byte("Hello, authenticated user! Token: " + sec.Bearer.Token))
    })

    http.ListenAndServe(":8080", mw.Handler(handler))
}
```

## Integration with Eugene Generator

The typical workflow is:

1. Write your OpenAPI spec
2. Generate server code with `eugene generate`
3. Protect your handlers with `eugene-middleware`

The generated handlers receive a typed security context:

```go
// Generated handler signature
func (s *Server) GetUsers(ctx context.Context, req *GetUsersRequest) (*GetUsersResponse, error) {
    // Access security context from middleware
    sec := middleware.GetSecurityContext(ctx)
    if sec.Bearer != nil {
        log.Printf("Authenticated with token: %s", sec.Bearer.Token)
    }
    // ... handler logic
}
```

## Security Schemes

### HTTP Bearer

```go
opts.Security.RegisterBearer("bearerAuth", func(ctx context.Context, token string) (*middleware.BearerAuth, error) {
    // Validate JWT, lookup token, etc.
    claims, err := validateJWT(token)
    if err != nil {
        return nil, middleware.NewUnauthorizedError("bearer", "invalid token")
    }
    return &middleware.BearerAuth{Token: token}, nil
})
```

**Auth result type:**
```go
type BearerAuth struct {
    Token string
}
```

### HTTP Basic

```go
opts.Security.RegisterBasic("basicAuth", func(ctx context.Context, username, password string) (*middleware.BasicAuth, error) {
    if !checkCredentials(username, password) {
        return nil, middleware.NewUnauthorizedError("basic", "invalid credentials")
    }
    return &middleware.BasicAuth{Username: username, Password: password}, nil
})
```

**Auth result type:**
```go
type BasicAuth struct {
    Username string
    Password string
}
```

### API Key

API keys can be sent in headers, query parameters, or cookies:

```go
// Header: X-API-Key
opts.Security.RegisterAPIKey("apiKeyHeader", handler, "header", "X-API-Key")

// Query: ?api_key=xxx
opts.Security.RegisterAPIKey("apiKeyQuery", handler, "query", "api_key")

// Cookie: api_key=xxx
opts.Security.RegisterAPIKey("apiKeyCookie", handler, "cookie", "api_key")
```

Handler signature:

```go
func(ctx context.Context, key string) (*middleware.APIKeyAuth, error) {
    if !isValidAPIKey(key) {
        return nil, middleware.NewUnauthorizedError("apiKey", "invalid API key")
    }
    return &middleware.APIKeyAuth{Key: key}, nil
}
```

**Auth result type:**
```go
type APIKeyAuth struct {
    Key      string
    Name     string // Parameter name from spec
    Location string // header, query, cookie
}
```

### OAuth2

```go
opts.Security.RegisterOAuth2("oauth2", func(ctx context.Context, token string, scopes []string) (*middleware.OAuth2Auth, error) {
    // Validate token and check scopes
    tokenScopes, err := introspectToken(token)
    if err != nil {
        return nil, middleware.NewUnauthorizedError("oauth2", "invalid token")
    }

    // Check required scopes
    if !hasScopes(tokenScopes, scopes) {
        return nil, middleware.NewForbiddenError("oauth2", "insufficient scopes", scopes)
    }

    return &middleware.OAuth2Auth{
        Token:  token,
        Scopes: tokenScopes,
        Flow:   "authorizationCode",
    }, nil
})
```

**Auth result type:**
```go
type OAuth2Auth struct {
    Token  string
    Scopes []string
    Flow   string // implicit, password, clientCredentials, authorizationCode, deviceAuthorization
}
```

### OpenID Connect

```go
opts.Security.RegisterOpenIDConnect("oidc", func(ctx context.Context, token string, scopes []string) (*middleware.OpenIDConnectAuth, error) {
    claims, err := verifyIDToken(token)
    if err != nil {
        return nil, middleware.NewUnauthorizedError("openIdConnect", "invalid token")
    }

    return &middleware.OpenIDConnectAuth{
        Token:  token,
        Scopes: claims.Scopes,
        Issuer: claims.Issuer,
    }, nil
})
```

**Auth result type:**
```go
type OpenIDConnectAuth struct {
    Token  string
    Scopes []string
    Issuer string
}
```

### Mutual TLS

```go
opts.Security.RegisterMutualTLS("mtls", func(ctx context.Context, cert *x509.Certificate) (*middleware.MutualTLSAuth, error) {
    // Verify client certificate
    if !isAllowedClient(cert) {
        return nil, middleware.NewUnauthorizedError("mutualTLS", "certificate not authorized")
    }

    return &middleware.MutualTLSAuth{
        Subject:     cert.Subject.CommonName,
        Issuer:      cert.Issuer.CommonName,
        Certificate: cert,
    }, nil
})
```

**Auth result type:**
```go
type MutualTLSAuth struct {
    Subject     string
    Issuer      string
    Certificate *x509.Certificate
}
```

## Security Logic

### OR Semantics (Multiple Requirements)

When multiple security requirements are listed in the OpenAPI spec, they form OR alternatives. The request passes if **any one** succeeds:

```yaml
security:
  - bearerAuth: []    # Option 1: Bearer token
  - apiKey: []        # Option 2: API key
```

### AND Semantics (Combined Schemes)

When multiple schemes are in the **same** requirement object, they form AND requirements. **All** must pass:

```yaml
security:
  - bearerAuth: []
    apiKey: []        # Both bearer AND apiKey required
```

In this case, the `SecurityContext` will have both `Bearer` and `APIKey` populated.

### Empty Security = Public Endpoint

An empty security requirement means the endpoint is public:

```yaml
security:
  - {}                # Public endpoint
  - bearerAuth: []    # Or authenticated
```

## Configuration Options

```go
opts := &middleware.Options{
    // Security registry for authentication handlers
    Security: middleware.NewSecurityRegistry(),

    // Validate request against OpenAPI spec (default: true)
    ValidateRequest: true,

    // Validate response against OpenAPI spec (default: false)
    ValidateResponse: false,

    // Custom error handler
    ErrorHandler: func(w http.ResponseWriter, r *http.Request, err error) {
        // Handle validation and auth errors
    },
}
```

Use `middleware.DefaultOptions()` for sensible defaults:
- `ValidateRequest: true`
- `ValidateResponse: false`
- Empty security registry

## Accessing Security Context

In your handlers, retrieve the validated security context:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    sec := middleware.GetSecurityContext(r.Context())
    if sec == nil {
        // Public endpoint or security not configured
        return
    }

    // Check which auth method was used
    if sec.Bearer != nil {
        log.Printf("Bearer token: %s", sec.Bearer.Token)
    }
    if sec.Basic != nil {
        log.Printf("Basic auth user: %s", sec.Basic.Username)
    }
    if sec.APIKey != nil {
        log.Printf("API key from %s", sec.APIKey.Location)
    }
    if sec.OAuth2 != nil {
        log.Printf("OAuth2 scopes: %v", sec.OAuth2.Scopes)
    }
    if sec.OpenIDConnect != nil {
        log.Printf("OIDC issuer: %s", sec.OpenIDConnect.Issuer)
    }
    if sec.MutualTLS != nil {
        log.Printf("Client cert subject: %s", sec.MutualTLS.Subject)
    }
}
```

## Error Handling

### Default Behavior

The middleware returns JSON error responses:

**Validation errors (400):**
```json
{
  "error": "validation_error",
  "message": "request validation failed",
  "details": [{"message": "...", "reason": "...", "howToFix": "..."}]
}
```

**Authentication errors (401):**
```json
{
  "error": "authentication_error",
  "message": "missing bearer token"
}
```

**Authorization errors (403):**
```json
{
  "error": "authentication_error",
  "message": "insufficient scopes",
  "required_scopes": ["read:users", "write:users"]
}
```

### Custom Error Handler

Override error handling with a custom function:

```go
opts.ErrorHandler = func(w http.ResponseWriter, r *http.Request, err error) {
    switch e := err.(type) {
    case *middleware.ValidationError:
        w.WriteHeader(http.StatusBadRequest)
        w.Write([]byte("Bad request: " + e.Message))
    case *middleware.AuthError:
        if e.IsUnauthorized() {
            w.Header().Set("WWW-Authenticate", "Bearer")
        }
        w.WriteHeader(e.StatusCode)
        w.Write([]byte(e.Message))
    default:
        w.WriteHeader(http.StatusInternalServerError)
        w.Write([]byte("Internal error"))
    }
}
```

### Error Constructors

Create auth errors in your handlers:

```go
// 401 Unauthorized - missing or invalid credentials
middleware.NewUnauthorizedError("bearer", "token expired")

// 403 Forbidden - valid credentials, insufficient permissions
middleware.NewForbiddenError("oauth2", "insufficient scopes", []string{"admin:write"})
```

